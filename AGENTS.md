# Development Guidelines

- Keep shared navigation and footer in the root route and each named learning view in its own leaf route, so navigation and page metadata remain consistent.
- Keep financial simulation formulas in a pure finance module with rule tests, so projections are consistent across all educational views.
- Use a reference-derived baked landscape plate in a lazy client-only R3F scene with restrained perspective parallax and a static image fallback, so visual fidelity and accessibility do not depend on WebGL.
- Educational plans are in-session simulations, not real accounts or investment execution; do not imply persistence or production authentication without adding it explicitly.
